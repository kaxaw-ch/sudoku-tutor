## 3. 精确定义、图形形态与解题作用

> 下表逐条给出"**精确定义（含图形形态条件）**"与"**在解题中的作用**"，覆盖 §2 全部 17 项。凡 doc 02 §3.1 标注"业界有歧义"的口径，已在定义中按**本期采用口径**写明（权威口径汇总见 §4）。

| 标准中文译名 | 精确定义（含图形形态条件） | 在解题中的作用 |
|---|---|---|
| 唯一余数 | 某一空格经其所在行、列、宫的已填数排除后，**仅剩恰好 1 个候选数**，则该格必填此数。图形形态：单格内其余 8 个候选被消干净。 | 最基础的"填数"动作，开局与中后期都高频出现。 |
| 隐性唯一数 | 在某个单元（行 / 列 / 宫）内，某候选数字 **d 只出现在唯一一格**中（该格可能还含其他候选），则该格必为 d。图形形态：单元内 d 的候选位仅 1 个。 | 唯一余数失效时的第一层兜底填数。 |
| 裸对 | 同一单元内**两格恰好同含候选集 {a,b} 且不含其它候选**，则 a、b 可从该单元其余格删除。图形形态：两格、同两候选，呈"成对"。 | 候选数剪枝，常是中高阶技巧的前置。 |
| 隐对 | 同一单元内**两候选 {a,b} 仅共同出现在两格**中（这两格可含其它候选），则这两格的其它候选可删，退化为裸对。图形形态：两格承载了该单元的 a、b 全部出现。 | 候选剪枝，是裸对的前置识别。 |
| 裸三 | 同一单元内**三格的候选全部取自集合 {a,b,c}（每格 2–3 个，三者合起来覆盖 a,b,c 全部）**，则 a,b,c 可从该单元其余格删除。图形形态：3 格、候选均为 {a,b,c} 子集。 | 候选剪枝，裸对的三元推广。 |
| 隐三 | 同一单元内**三候选 {a,b,c} 仅出现在三格**中（可含其它候选），则这三格的其它候选可删。图形形态：a,b,c 的全部出现被锁在这 3 格。 | 候选剪枝，隐对的三元推广。 |
| 区块排除 | 含两情形：①**指针法（Pointing）**——某宫内候选 d 只出现在该宫的同一行（或同一列），则 d 可从该宫外的同行/列删除；②**占位法（Claiming）**——某行/列内候选 d 只出现在同一宫，则 d 可从该宫其余格删除。图形形态：候选被"封锁"在一条线（或一条线被锁在一个宫）。 | 跨单元的候选剪枝，常桥接行/列/宫。 |
| X 翼 | 某数字在**恰好两行**中各只出现在**相同两列**，则这两列中其余行的该数字可删（列-行对偶同理）。图形形态：2 行 × 2 列构成的候选"矩形四角"。 | 最基础的 Fish（鱼形）剪枝，引入跨单元链思想。 |
| 鳍形 X 翼（含 Sashimi） | 在 X 翼基础上，其中一行（列）的该数字候选**多出一个位于两列之外的"鳍（fin）"格且鳍被限制在同一宫内**；则同时能看到一个角点与该鳍的格可删此数。**Sashimi 退化形态**：四角中某一角点本身不含该候选，但结论依然成立——本期**将 Sashimi 归入 Finned X-Wing 一并实现**。图形形态：2×2 矩形 + 1 个同宫鳍格。 | Fish 的"不完美"推广，命中率高于标准 X 翼。 |
| 剑鱼（标准） | X 翼向 N=3 的推广：某数字在**恰好三行**中各只出现在**相同三列**（或对偶），则这三列中其余行的该数字可删。**本期仅标准形态**，不含 Jellyfish(N=4)；当退化为 X 翼时不重复上报、优先报更简单技巧。图形形态：3 行 × 3 列的候选阵。 | Fish 三阶剪枝，与 X 翼共用 `Fish(N)` 泛化框架。 |
| XY 翼 | 三格：枢轴格（pivot）候选 {a,b}，两夹翼格（pincer）候选分别为 {b,c}、{a,c}，且 pivot 同时看到两 pincer；则**同时能看到两 pincer 的格**不能填 c。图形形态：pivot + 两个分叉 pincer 的"翼"形。 | 基于双值格的链剪枝，困难档核心。 |
| XYZ 翼 | 枢轴格候选 {a,b,c}（三值），两 pincer 各与 pivot 共享两候选（如 {b,c}、{a,c}）；则**同时能看到 pivot 与两 pincer 全部三格的格**不能填 c。图形形态：三值 pivot + 两 pincer。 | XY 翼的三值推广，剪枝更强。 |
| W 翼 | 两格均为双值 {a,b}，通过**某单元内 b 的严格共轭对（该单元内 b 恰好 2 个候选位，构成强链）**相连，且两 {a,b} 格各看到该强链的一端；则**同时能看到两 {a,b} 格的格**不能填 a。本期**采用严格共轭对定义**（不含分组/ALS 强链）。图形形态：两 {a,b} 格 + 一段长度为 2 的 b 强链。⚠️ 见 §5 特别标注。 | 形似"带颜色的 XY 翼"，困难档高阶剪枝。 |
| 唯一矩形 型一 | 四格构成 **2 行 × 2 列 × 恰好 2 宫**的矩形，**四格全为非给定格（非原题提示格）**，且其中两格恰含 {a,b}、另两格含 {a,b}+额外候选；基于"致命模式（deadly pattern）会破坏唯一解"的前提，那两格的额外候选可删。图形形态：2×2 矩形、跨 2 宫。⚠️ 前提见 §4。 | 依赖唯一解假设的高级剪枝（大师档）。 |
| 唯一矩形 型二 | 同 UR 型一的全部前提，且两个"额外候选"格**同时含同一个额外候选 c**；则**同时能看到这两格的格**中的 c 可删。图形形态：UR 矩形 + 共享额外候选 c。 | UR 型一的推广，大师档。 |
| 简单涂色 | 对单一数字构建**共轭对图（强链）**并做双色 BFS 染色，采用两条规则：①**同色重复（Color Wrap / Rule 2）**——同色两格互相可见 → 该色全假，删其全部该数字候选；②**双色可见（Color Trap / Rule 4）**——某格同时看到两色 → 该格不能填该数字。本期**仅 Rule 2 + Rule 4**，不含多色（Multi-Colouring）。图形形态：单数字双色链。 | 链式剪枝，是 AIC 的"单数字直觉版"，大师档。 |
| 基础交替推理链 | 单数字上由**强链 / 弱链交替**构成的推理链：**仅单候选数节点**（不含分组/ALS）、**链长 ≤ 7（链接数 ≤ 约 10）**、双端为**同一数字**、仅**不连续环（discontinuous loop）**；若某格同时看到链两端，则删该数字。图形形态：单数字强弱交替链。⚠️ 受限口径见 §4。 | 最通用的链式剪枝，覆盖前述多数技巧，大师档、风险最高。 |

## 5. W 翼特别标注（原文档六章无教学章节）

**问题**：客户原始需求六章教学大纲中**没有任何一章教 W 翼**，但引擎要求识别它（doc 00 矛盾清单 D-03）。W 翼本质是 XY 翼的"共轭对版"，形态较特殊，属于困难档晚期技巧。

**两个选项（请客户二选一或采纳建议）**：

- **选项 A —— 加章节**：把 W 翼作为"困难章（第 3 章）"末尾的一节正式教学关。复用 XY 翼的教学铺垫，构图与文案成本可控；优点是与"引擎识别即教学覆盖"一致，玩家能在正式关卡里学到。
- **选项 B —— 仅引擎实现 + 图文讲解**：引擎必须识别 W 翼（用于提示、解题器与题库筛选），但**不设正式教学关**；在「提示」功能与「技巧百科」中以 AI 生成文案 + 人工校订的方式给出标准图解讲解。优点是不增加正式关卡构造成本，缺点是无"手把手"关卡。

> **架构建议**：**采用选项 B（仅引擎实现 + 百科/提示图文讲解）作为默认**。理由：W 翼命中率低、形态特殊，正式关卡教学效果边际收益低而构图/审校成本高；引擎识别是硬需求（提示与求解器必须支持），而"学会 W 翼"可通过百科词条与实时提示满足，不阻塞 P0 交付。若客户坚持正式关卡，则按选项 A 并入第 3 章末尾，工期增量约 +1–2 人日。
