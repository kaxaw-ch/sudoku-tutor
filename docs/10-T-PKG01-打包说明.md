## 1. 宿主机一键构建（推荐）

### 1.1 前置条件
| 项 | 要求 | 备注 |
|---|---|---|
| OS | Windows 10 1809（build 17763）及以上 x64 | 见 Inno Setup `MinVersion` |
| Flutter | 3.44.8 已就绪 | 已验证：`C:\dev\flutter\bin\flutter` |
| MSVC / CMake / Windows SDK | 已就绪 | 已验证（见 `scripts/verify_env.ps1`） |
| Android SDK / JDK 17 | 已就绪 | 已验证可产出 `app-debug.apk` |
| PowerShell | 5.1 或 7+ | `pwsh` 或 `powershell` |
| Python + Pillow | 可选 | 仅替换品牌图标时需要（见 `docs/替换品牌资产说明.md`） |
| Inno Setup 6 | 可选 | 未装则仅产出绿色版 zip，Setup.exe 步骤跳过 |

将 `C:\dev\flutter\bin` 加入 PATH（用户登录 shell 已默认包含）；FVM 用户请自行用 `fvm flutter ...`。

### 1.2 一键命令
在项目根目录打开 PowerShell：
```powershell
pwsh .\scripts\build_release.ps1
```

脚本会依次执行：
1. `flutter build windows --release`
2. 复制 `app\build\windows\x64\runner\Release\*` 到 `dist\SudokuTutor-windows-x64\` 并 `Compress-Archive` 为 zip
3. `flutter build apk --debug`（abiFilters 限定 arm64-v8a + armeabi-v7a，产单个 apk）
4. 若检测到 ISCC.exe，编译 `installer\sudoku_tutor.iss` 生成 `Setup.exe`

参数：
- `-SkipWindows`   仅构建 Android apk
- `-SkipAndroid`   仅构建 Windows（绿色版 + Setup.exe）
- `-SkipInnoSetup` 跳过 Setup.exe 生成（绿色版 zip 仍产出）

### 1.3 失败即停
`$ErrorActionPreference='Stop'`，任一步骤非 0 退出码即中止。请按终端输出定位错误（构建错误通常在 `flutter build` 输出尾部）。

## 2. 手动构建（逐步）

### 2.1 Windows Release（绿色版优先交付物）
```powershell
cd app
flutter build windows --release
# 产物：app\build\windows\x64\runner\Release\
#       ├── sudoku_tutor.exe
#       ├── *.dll
#       └── data\  （含 icudtl / flutter_assets）

# 复制到 dist\ 作为绿色版目录
$greenDir = "..\dist\SudokuTutor-windows-x64"
Remove-Item -Recurse -Force $greenDir -ErrorAction SilentlyContinue
New-Item -ItemType Directory -Path $greenDir -Force | Out-Null
Copy-Item -Recurse -Force `
  "build\windows\x64\runner\Release\*" `
  $greenDir

# 打绿色版 zip（双击解压即可运行，无需安装）
$zip = "..\dist\SudokuTutor-windows-x64.zip"
Remove-Item -Force $zip -ErrorAction SilentlyContinue
Compress-Archive -Path (Get-ChildItem -Recurse -File $greenDir).FullName -DestinationPath $zip
```

### 2.2 Android APK（abiFilters 限定双 ABI）
```powershell
cd app
flutter build apk --debug
# 产物：app\build\app\outputs\flutter-apk\
#       └── app-debug.apk   （约 50 MB，原生库仅含 arm64-v8a + armeabi-v7a）
```

abiFilters 已写入 `app\android\app\build.gradle.kts`，仅产 arm64-v8a + armeabi-v7a 两种架构的原生库（单个 APK）：
```kotlin
ndk {
    abiFilters += listOf("arm64-v8a", "armeabi-v7a")
}
```

### 2.3 Inno Setup 安装包（次级产物）
```powershell
# 安装 Inno Setup 6：https://jrsoftware.org/isdl.php
# 默认路径：C:\Program Files (x86)\Inno Setup 6\ISCC.exe

& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer\sudoku_tutor.iss
# 产物：dist\Setup-SudokuTutor-0.1.0.exe
```

## 3. SmartScreen / 安全提示

### 3.1 现象
- **绿色版 zip 解压后双击 `sudoku_tutor.exe`**：Windows Defender SmartScreen 可能弹出"Windows 已保护你的电脑"提示。
- **Setup.exe 安装时**：首次安装同样会触发 SmartScreen。

原因：本期未申请代码签名证书（OV / EV），exe 无 Authenticode 签名，SmartScreen 无信誉数据。

### 3.2 三条处理路径（按出货要求选）

| 路径 | 做法 | 适用 |
|---|---|---|
| A. 用户告知 | README / 安装指引中写明"首次启动需点 更多信息 → 仍要运行" | 内测 / 受控分发 |
| B. 自签名测试证书 | 用 `signtool` + 自建 CA 给 exe 签名（仅本机信任） | 单机演示 |
| C. 商业代码签名证书 | 申请 OV（如 Comodo / DigiCert），CI 集成 `signtool sign /tr ...`，建立 SmartScreen 信誉 | 正式出货 |

### 3.3 客户告知文案（贴入 README）
> 首次启动时，Windows 可能弹出"Windows 已保护你的电脑"提示。
> 这是因为本应用尚未购买代码签名证书。点击"更多信息 → 仍要运行"即可正常启动。
> 如需消除该提示，请联系项目方获取正式签名版本。

## 4. 产物路径清单

`dist/` 目录（`scripts/build_release.ps1` 完成后）：
```
dist/
├── SudokuTutor-windows-x64/                  ← 绿色版目录（可直接复制运行）
│   ├── sudoku_tutor.exe
│   ├── *.dll
│   └── data/
├── SudokuTutor-windows-x64.zip                ← 绿色版 zip（首选交付物）
└── Setup-SudokuTutor-0.1.0.exe                ← Inno Setup 安装包（若本机有 ISCC）
```

`app/build/` 目录（Flutter 自动生成）：
```
app/build/
├── windows/x64/runner/Release/               ← Windows Release 中间产物
│   ├── sudoku_tutor.exe
│   └── ...
└── app/outputs/flutter-apk/
    ├── app-debug.apk                           ← Android（双 ABI 单包）
    └── app-armeabi-v7a-debug.apk              ← Android 32 位
```

## 5. 版本号 / 应用名 / 包名 现状确认

| 项 | 值 | 来源 |
|---|---|---|
| 应用版本 | `0.1.0+1`（versionCode=1） | `app/pubspec.yaml` 的 `version:` 字段 |
| 应用显示名（Windows 窗口） | `sudoku_tutor`（默认） | `app/windows/runner/main.cpp:30` |
| 应用显示名（Android 启动器） | `sudoku_tutor`（默认） | `app/android/app/src/main/AndroidManifest.xml:3` |
| Android applicationId | `sudututor.app.sudoku_tutor` | `app/android/app/build.gradle.kts:19` |
| Android namespace | `sudututor.app.sudoku_tutor` | `app/android/app/build.gradle.kts:8` |
| Android abiFilters | `arm64-v8a`, `armeabi-v7a` | T-PKG-01 写入 `app/android/app/build.gradle.kts` |
| Windows 安装目录 | `{autopf}\SudokuTutor` | `installer/sudoku_tutor.iss` |
| Windows 最低系统 | `Win10 1809` (build 17763) x64 | `installer/sudoku_tutor.iss` MinVersion |

> **关于包名前缀**：客户约定调试前缀为 `sudututor.app`，实际 Android applicationId / namespace 因 Flutter 模板默认追加 `.sudoku_tutor` 后缀，最终为 `sudututor.app.sudoku_tutor`。若客户严格要求 `sudututor.app` 作为顶层 ID，请同步修改 `app/android/app/build.gradle.kts` 第 8 行（`namespace`）和第 19 行（`applicationId`），并重跑 `flutter build apk`。
