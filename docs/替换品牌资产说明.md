# 替换品牌资产说明（T-PKG-01）

> 适用范围：替换默认占位图标、应用显示名、Windows / Android 元数据。
> 本文档面向主理人/客户工程师。所有替换均不涉及 Dart lib 代码；仅编辑资源文件或 `app/pubspec.yaml`。
> 当前默认状态已可构建可运行，替换仅在需要"出货级品牌外观"时执行。

---

## 1. 应用图标

### 1.1 占位现状
T-PKG-01 已生成占位图标（数独九宫格 + 蓝色引导箭头）：
- `app/assets/images/icon_placeholder.png`（1024×1024，PNG，透明圆角方底）
- `app/assets/images/icon_placeholder.ico`（多尺寸 ICO：16/32/48/64/256，备用）

### 1.2 Windows 替换目标
目标文件：`app/windows/runner/resources/app_icon.ico`（当前为 Flutter 默认占位）。

**方法 A：直接覆盖（推荐）**
若占位图标已能满足需求：
```powershell
Copy-Item `
  -Path app/assets/images/icon_placeholder.ico `
  -Destination app/windows/runner/resources/app_icon.ico `
  -Force
```

**方法 B：从 PNG 重新生成 ICO（推荐用于真实品牌图标）**

使用 ImageMagick（需先安装 `magick`）：
```powershell
magick convert icon_1024.png `
  -define icon:auto-resize=256,48,32,16 `
  app/windows/runner/resources/app_icon.ico
```

使用 Python + Pillow（无 ImageMagick）：
```python
from PIL import Image
Image.open(r"icon_1024.png").save(
    r"app/windows/runner/resources/app_icon.ico",
    "ICO",
    sizes=[(256, 256), (48, 48), (32, 32), (16, 16)],
)
```

替换后下次 `flutter build windows` 会被嵌入到 `sudoku_tutor.exe`。

### 1.3 Android 替换目标
各密度 mipmap 图标（当前均为 Flutter 默认）：
| 目录 | 文件 | 像素 |
|---|---|---|
| `app/android/app/src/main/res/mipmap-mdpi/` | `ic_launcher.png` | 48×48 |
| `app/android/app/src/main/res/mipmap-hdpi/` | `ic_launcher.png` | 72×72 |
| `app/android/app/src/main/res/mipmap-xhdpi/` | `ic_launcher.png` | 96×96 |
| `app/android/app/src/main/res/mipmap-xxhdpi/` | `ic_launcher.png` | 144×144 |
| `app/android/app/src/main/res/mipmap-xxxhdpi/` | `ic_launcher.png` | 192×192 |

**方法：ImageMagick 批量生成**
```powershell
magick convert icon_1024.png -resize 48x48   app/android/app/src/main/res/mipmap-mdpi/ic_launcher.png
magick convert icon_1024.png -resize 72x72   app/android/app/src/main/res/mipmap-hdpi/ic_launcher.png
magick convert icon_1024.png -resize 96x96   app/android/app/src/main/res/mipmap-xhdpi/ic_launcher.png
magick convert icon_1024.png -resize 144x144 app/android/app/src/main/res/mipmap-xxhdpi/ic_launcher.png
magick convert icon_1024.png -resize 192x192 app/android/app/src/main/res/mipmap-xxxhdpi/ic_launcher.png
```

替换后下次 `flutter build apk` 会被打包进 APK。

## 2. 应用显示名

### 2.1 当前默认（《数独学堂》/ sudoku_tutor）
- Windows 窗口标题：`app/windows/runner/main.cpp:30` `window.Create(L"sudoku_tutor", ...)`
- Android 启动器标签：`app/android/app/src/main/AndroidManifest.xml:3` `android:label="sudoku_tutor"`
- Windows 资源元数据（产品名/文件描述/版权/发布者）：`app/windows/runner/Runner.rc:92-99`

### 2.2 改法
- **Windows 窗口标题**（最直观）：编辑 `app/windows/runner/main.cpp` 第 30 行，把 `L"sudoku_tutor"` 改为 `L"数独学堂 SudokuTutor"`（注意源文件需 UTF-8 BOM 或 UTF-16 LE，Windows MSVC 默认按系统代码页解析宽字符串字面量；含中文请用 `L"\x6570\x72ec\x5b66\x5802"` 形式或保存为 UTF-8 BOM 并在 CMakeLists 中加 `/utf-8` 编译选项）。
- **Android 启动器标签**：编辑 `app/android/app/src/main/AndroidManifest.xml` 第 3 行，`android:label="数独学堂"`（Android 资源是 UTF-8，直接中文即可）。
- **Windows 产品元数据**：编辑 `app/windows/runner/Runner.rc` 第 92-99 行（`VALUE "ProductName"` / `"FileDescription"` / `"CompanyName"` 等）。修改后 `flutter build windows` 会触发资源编译器重新嵌入。

### 2.3 本期（T-PKG-01）结论
显示名沿用《数独学堂》临时命名（doc 01 P-33），**本期不实际修改**上述三个文件。
`main.cpp` / `AndroidManifest.xml` / `Runner.rc` 保留 Flutter 默认值（`sudoku_tutor`）。
待客户提供正式产品名后，按 §2.2 一次性替换。

## 3. 启动图（Splash）

Flutter Windows / Android 默认无自定义启动图，使用平台默认主题色。

**本期不引入** `flutter_native_splash`（新增依赖违反 doc 06 §1 约束：禁止引入未在依赖清单的包）。

若后续需要：
1. 在 `app/pubspec.yaml` 的 `dev_dependencies` 增加 `flutter_native_splash: ^2.x`；
2. 在 `app/` 下准备 `splash.png`（建议 1242×2436 等高分辨率）；
3. `dart run flutter_native_splash:create`；
4. 提交自动生成的 `flutter_native_splash.yaml` 与平台资源。
