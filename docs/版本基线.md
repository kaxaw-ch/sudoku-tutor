# 版本基线（Version Baseline）

> 用途：锁定全项目依赖与工具链版本，确保「.fvmrc + 三份 pubspec.lock + 本文档」三处同步。
> 编制：主理人（依据 doc 06 §1 依赖包清单与 doc 05 PRD 基线）。日期：2026-08-05

## 1. Flutter / Dart 运行时
- **Flutter**：`3.x` 稳定版（具体补丁版本待客户运行 `scripts/verify_env.ps1` 后写回 `.fvmrc` 锁定）。
- **Dart SDK**：随所选 Flutter 版本捆绑，不单独锁定（由 `.fvmrc` 间接锁定）。
- 锁定流程：客户 `verify_env.ps1` 报告可用版本 → 写入仓库根 `.fvmrc` → `flutter pub get` 生成各包 `pubspec.lock` → 本文档登记补丁号。

## 4. 开发工具
- FVM（可选）：用于 `.fvmrc` 锁定 Flutter 版本；不强制，直接装稳定版 Flutter 亦可。
- Inno Setup 6（可选，仅打包期）：本期绿色 zip 优先，Setup.exe 次级产物，见 doc 06 §8 A-04。

## 5. 同步规则（铁律）
1. 升级任一依赖版本 → 同步改三处：`.fvmrc`（如涉及运行时）、各包 `pubspec.yaml`、本文档 §2/§3。
2. `pubspec.lock` 纳入版本管理，禁止 `--flush`。
3. 新增依赖前须确认不引入：数据库 / 网络 / file_picker / Lottie / Rive / CJK 字体包（见 doc 06 §1）。
