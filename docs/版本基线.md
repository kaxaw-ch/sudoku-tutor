# 版本基线（Version Baseline）

> 用途：锁定全项目依赖与工具链版本，确保 `.fvmrc`、各包 `pubspec.yaml` / `pubspec.lock` 与本文档同步。
> 编制：主理人（依据 doc 06 §1 依赖包清单与 doc 05 PRD 基线）。初版：2026-08-05；最近核验：2026-09-01。

## 1. Flutter / Dart 运行时
- **Flutter**：`3.44.8`（stable），由仓库根 `.fvmrc` 固定。
- **Dart SDK**：`3.12.2`，随 Flutter 3.44.8 捆绑，不单独安装。
- **核验来源**：本机 `C:\dev\flutter\bin\cache\flutter.version.json` 与 `dart-sdk/version`；重新生成锁文件前先运行 `scripts/verify_env.ps1`。

## 4. 开发工具
- FVM（可选）：用于 `.fvmrc` 锁定 Flutter 版本；不强制，直接装稳定版 Flutter 亦可。
- Inno Setup 6（可选，仅打包期）：本期绿色 zip 优先，Setup.exe 次级产物，见 doc 06 §8 A-04。

## 5. 同步规则（铁律）
1. 升级任一依赖版本 → 同步更新 `.fvmrc`（如涉及运行时）、对应 `pubspec.yaml` / `pubspec.lock` 与本文档 §2/§3。
2. `pubspec.lock` 纳入版本管理，禁止 `--flush`。
3. 新增依赖前须确认不引入：数据库 / 网络 / file_picker / Lottie / Rive / CJK 字体包（见 doc 06 §1）。
