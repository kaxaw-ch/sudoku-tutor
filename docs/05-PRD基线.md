### 0.1 原始需求复述（一句话）

面向零基础到进阶玩家的**跨端离线数独教学游戏**：不只提供数独玩法，而是把 16 项人类解题技巧拆成分级课程，通过「原理演示 → 引导实操 → 验收试炼」三段式关卡逐步教会玩家，并提供带技巧提示的自由练习。所有题目离线内置，无需联网。

---

## 1. 产品目标

**做一款能真正把人「教会」的离线数独产品。** 玩家不需要任何数独基础，也不需要去网上翻攻略：从行/列/宫规则与候选数概念开始，沿着「唯一余数 → 裸对/隐对/区块排除 → 裸三/隐三/X 翼 → 鳍形 X 翼/剑鱼 → XY 翼/XYZ 翼 → 唯一矩形 → 简单涂色」这条**逐级递进的课程主线**，每一项技巧都经历「看懂原理（分步动画演示）→ 有人扶着练（三级梯度提示 + 误操作即时纠正）→ 独立通关（无提示试炼）」三个环节；学完后进入五档难度自由练习巩固，遇到卡壳可随时调用同一套技巧引擎给出提示。全部内容离线内置于安装包，Windows 与 Android 双端体验一致，不联网、不注册、不打扰。

## 2. 用户故事

> 角色定义：**新手**（零数独基础）｜**进阶玩家**（会基础填数，卡在中高级技巧）｜**熟练玩家**（想自由练习/挑战难度）｜**回访玩家**（断断续续玩，需要复习与续玩）

| # | 角色 | 用户故事 | 覆盖需求 |
|---|---|---|---|
| US-01 | 新手 | 作为一个从没玩过数独的人，我希望看到清晰的推荐学习路线，同时也能按兴趣自由选择任意教程。 | 学习地图/章节列表、全课程自由选关 |
| US-02 | 新手 | 作为新手，我希望第 0 章先用不可操作的分步动画讲清行/列/宫规则与候选数是什么，这样我在动手前就已经看懂了。 | 原理演示关、第 0 章 |
| US-03 | 新手 | 作为新手，我希望学完裸对后立刻有一盘题让我自己找裸对，卡住时能一级一级地要提示而不是直接看答案，这样我是被"扶着"学会的，不是被喂答案。 | 引导实操关、三级梯度提示 |
| US-04 | 新手 | 作为新手，我希望填错数或删错候选数时马上弹窗告诉我"错在哪、该怎么想"，而不是等我整盘做废才发现。 | 误操作即时纠正弹窗 |
| US-05 | 进阶玩家 | 作为已经会基础填数的玩家，我希望能看懂 X 翼到底在哪两行两列上成立，系统能用虚线矩形和高亮把这四个角点画出来，这样我不用靠脑补。 | 教学可视化（高亮/矩形/连线/文字） |
| US-06 | 进阶玩家 | 作为进阶玩家，我希望进阶鱼形章能把"鳍"是什么、Sashimi 为什么仍然成立讲清楚，这是我在别的 App 里一直没搞懂的地方。 | 第 2 章、鳍形 X 翼（含 Sashimi） |
| US-07 | 进阶玩家 | 作为进阶玩家，我希望在翼形章学完 XY 翼后能立刻做一道只含 XY 翼的试炼题，靠自己识别出来并解完，用来确认我真的学会了。 | 验收试炼关、第 3 章 |
| US-08 | 进阶玩家 | 作为进阶玩家，我希望每章学完有一关综合试炼，题目里确实存在本章技巧，我需要自己找出来——系统不追问我"你是不是用了这招"，只要我把盘面解完就算过。 | 验收试炼关判定口径（不强校验） |
| US-09 | 熟练玩家 | 作为熟练玩家，我希望自由练习能按入门/简单/中等/困难/大师五档选题，难度是按"解这题最高要用到哪个技巧"划分的，而不是按空格数量瞎分。 | 五档难度、难度分级器 |
| US-10 | 熟练玩家 | 作为熟练玩家，我希望自由练习里卡住时能点提示，第一级告诉我"这里可以用鳍形 X 翼"并高亮相关格，第二级直接替我删数，但**永远不要直接告诉我某格填几**。 | 自由练习两级提示 |
| US-11 | 熟练玩家 | 作为熟练玩家，我希望能开自动候选数、错误标红、计时、相同数字高亮这些开关，按自己的习惯配置。 | 自由练习设置项 |
| US-12 | 回访玩家 | 作为一个玩两天停三天的人，我希望退出时自动保存当前这局（盘面、笔记、用时、撤销栈），下次打开能接着玩。 | 单局断点续玩、本地存档 |

| US-17 | 全体 | 作为同时用电脑和手机的人，我希望 Windows 上能用键盘方向键+数字键快速填数，手机上有常驻的九宫格键盘不遮挡盘面。 | 双端输入适配 |

#### 3.1.6 教学框架

| 编号 | 需求 | 说明 |
|---|---|---|
| P0-EDU-01 | 课程数据管线：`assets/curriculum/` 一关一 JSON + `index.json` 清单；新增一关 = 加文件 + 登记一行，**不改逻辑代码** | 关卡 JSON schema 由架构师定义 |
| P0-EDU-02 | **原理演示关控制器**：盘面**只读不可填数**；按预置解题脚本分步推进；**默认手动点「下一步」**，另提供「自动播放」（2s/步，可暂停）、「上一步」、「重播」；增加技巧进度条，在对应步骤标出技巧节点并支持点击快速跳转；首次进入须完整看完，之后可跳过 | 双模式统一控制条 + 技巧时间轴 |
| P0-EDU-03 | **教学可视化渲染**（CustomPaint）：多色单元格高亮、虚线矩形描边（可流动）、单元格连线生长动画（200–400ms 缓动）、候选数划除动画、步骤文字旁白区 | 数据全部来自 P0-ENG-09 |
| P0-EDU-04 | **引导实操关控制器**：玩家自主填数/标记；**三级梯度提示**，**必须逐级解锁**（一级→二级→三级），**次数不限**、不扣分、不消耗资源 | 一级=指出"本处可用 XX 技巧"并高亮区域；二级=点明构成技巧的关键格；三级=直接给出该技巧的删数结论 |
